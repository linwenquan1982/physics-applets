The setup

Set this to 1.00 for a plate that absorbs nothing at all.

1.00 is a true point source, where amplitude falls as 1/r. 0 is a perfectly collimated beam that never weakens. Real sources sit in between.

Starting points

For the answer

(b) How the stationary wave is formed [2]

  1. The microwaves travelling from the source to the plate are reflected at the metal surface, so a reflected wave travels back along the same line towards the source.
  2. The incident and reflected waves have the same frequency and a constant phase relationship, so they superpose to give a resultant with nodes and antinodes at fixed positions.

The metal forces a node at its surface: the reflection produces a phase change of π.

(c)(i) Why a minimum is never zero [3]

  1. At a minimum the two waves arrive exactly out of phase, so they interfere destructively.
  2. At that point the reflected wave has travelled further from the source than the incident wave, and the plate does not reflect all of the energy, so the reflected wave has the smaller amplitude.
  3. Since the amplitudes are unequal the cancellation is incomplete. The resultant amplitude is A₁ − A₂, which is not zero, so the intensity at a minimum is not zero.

Misconceptions this is built to catch

“A node has zero displacement, so the intensity must be zero.”

That is true only when the two waves have equal amplitudes. Set the spreading to 0 and the reflected fraction to 1.00 and the nodes do fall to zero — move either control away and they lift off the axis.

“The reflected wave is weaker because the metal absorbs some energy.”

That is one reason, but not the only one. Set the reflected fraction to 1.00 and keep the spreading: the minima are still non-zero, because the returning wave has spread over a longer path.

“At a node, no wave reaches the detector.”

Both waves arrive with full strength. Untick the resultant, freeze the animation and step through a cycle: two sizeable curves are always there, opposite in sign and unequal in size.

“All the minima should be the same height.”

They are not, because the mismatch between the two amplitudes changes with position. The mismatch shrinks close to the plate, so the minima there are deeper.

The model behind the animation

With the source at x = 0 and the plate at x = D:

y₁ = (a/x^p) sin(kx − ωt)

y₂ = (Ra/(2D−x)^p) sin(k(2D−x) − ωt + π)

A small constant is added to each distance before raising it to the power p, so that the amplitude stays finite right next to the source. A real source has a finite size, so nothing sharp happens there.

The reflected wave is written as though it came from an image source behind the plate, a distance 2D from the real one. Superposing gives a resultant amplitude

A = √(A₁² + A₂² + 2A₁A₂ cos δ), δ = 2k(x − D) − π

At a node cos δ = −1, so A = |A₁ − A₂|; at an antinode A = A₁ + A₂. Because 2D − x > x everywhere between the source and the plate, A₂ < A₁ always.
